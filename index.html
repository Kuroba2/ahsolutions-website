01 / PRODUCT & PROTOTYPE

Introducing AH BriefFlow.

An early-stage client-brief workflow concept for small software agencies and independent development teams. A browser-only, rule-based prototype is available for testing; the Claude agent is not implemented yet.

INTERACTIVE PRODUCT DEMO

From unstructured briefs to a reviewable first project plan.

The problem: Client requirements often arrive as long documents, fragmented messages, and incomplete descriptions. Teams must manually clarify scope before they can prepare reliable proposals.

For: Small software agencies and independent development teams handling early-stage client requests.

Proposed outcome: A structured first draft that people can check, edit, and approve.

04 / DELIVERY & VALIDATION PLAN

What works now.
What we test next.

The planned Claude integration addresses a specific limitation: rule-based sentence extraction often confuses background facts, requirements, exclusions, and undecided items.

AVAILABLE NOW

Browser prototype

Paste a text brief; classify candidate statements; suggest clarification questions; edit and download a proposal outline. Processing uses local browser rules.

NEXT ENGINEERING STEP

Evaluate Claude API

Compare Claude's structured classification and context-sensitive questions against this baseline. Explore tool use only where it improves reviewable output.

HOW WE PLAN TO EVALUATE

Measure useful differences

Use permitted or fictional briefs, and review missed requirements, unsupported additions, and how much human correction each output needs.
